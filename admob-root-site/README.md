# Root GitHub Pages Files for `ampthillsoftware.github.io`

These files are intended for the GitHub Pages **user site** repository named:

- `ampthillsoftware.github.io`

## Files

- `app-ads.txt`
- `index.html`

## Publish Steps

1. Clone or open the `ampthillsoftware.github.io` repository.
2. Copy these files into the repository root.
3. Commit and push to the branch GitHub Pages serves from, usually `main`.
4. Wait for GitHub Pages to deploy.
5. Confirm these URLs work:
   - `https://ampthillsoftware.github.io/app-ads.txt`
   - `https://ampthillsoftware.github.io/`

## AdMob Verification

Once `https://ampthillsoftware.github.io/app-ads.txt` is live:

1. Keep the Google Play developer website set to:
   `https://ampthillsoftware.github.io/`
2. In AdMob, open the app's `app-ads.txt` status page.
3. Click `Check for updates`.
